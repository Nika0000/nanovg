---
title: OpenGL and OpenGL ES
description: Create and use NanoVG with OpenGL 2, OpenGL 3, OpenGL ES 2, or OpenGL ES 3.
---

The OpenGL backend is implemented by `nanovg_gl.h`. Select exactly one variant in one translation unit:

```c
#include <nanovg/nanovg.h>

#define NANOVG_GL3_IMPLEMENTATION
#include <nanovg/nanovg_gl.h>
```

Available macro and function pairs are:

| Variant | Implementation macro | Create/delete functions |
| --- | --- | --- |
| OpenGL 2 | `NANOVG_GL2_IMPLEMENTATION` | `nvgCreateGL2()`, `nvgDeleteGL2()` |
| OpenGL 3 | `NANOVG_GL3_IMPLEMENTATION` | `nvgCreateGL3()`, `nvgDeleteGL3()` |
| OpenGL ES 2 | `NANOVG_GLES2_IMPLEMENTATION` | `nvgCreateGLES2()`, `nvgDeleteGLES2()` |
| OpenGL ES 3 | `NANOVG_GLES3_IMPLEMENTATION` | `nvgCreateGLES3()`, `nvgDeleteGLES3()` |

Create NanoVG only after the GL context is current and function loading is complete:

```c
NVGcontext* vg = nvgCreateGL3(NVG_ANTIALIAS | NVG_STENCIL_STROKES | NVG_DEBUG);
```

## Per-frame setup

Bind a framebuffer with stencil storage, set its viewport, and clear stencil before `nvgBeginFrame()`. The maintained `example_gl3` computes pixel ratio from framebuffer width divided by window width.

NanoVG changes OpenGL program, buffers, textures, blending, culling, depth, scissor, color mask, and stencil state while flushing. Restore required state or invalidate the host renderer's state cache after `nvgEndFrame()`.

## Offscreen rendering

`nanovg_gl_utils.h` provides an FBO helper whose color attachment is exposed as a NanoVG image. See [Framebuffers and render targets](/guides/framebuffers).

Destroy NanoVG before destroying the GL context:

```c
nvgDeleteGL3(vg);
```
