Every shape begins with `nvgBeginPath()`. Add one or more subpaths, choose a fill or stroke style, and render the path.

<LiveExample code={shapesExample} />

## Built-in primitives

```c
/* Rectangle */
nvgBeginPath(vg);
nvgRect(vg, 20.0f, 20.0f, 120.0f, 56.0f);
nvgFillColor(vg, nvgRGB(14, 165, 233));
nvgFill(vg);

/* Rounded rectangle */
nvgBeginPath(vg);
nvgRoundedRect(vg, 160.0f, 20.0f, 120.0f, 56.0f, 12.0f);
nvgFillColor(vg, nvgRGB(139, 92, 246));
nvgFill(vg);

/* Circle and ellipse */
nvgBeginPath(vg);
nvgCircle(vg, 60.0f, 130.0f, 32.0f);
nvgEllipse(vg, 180.0f, 130.0f, 52.0f, 28.0f);
nvgFillColor(vg, nvgRGB(16, 185, 129));
nvgFill(vg);
```

Multiple primitives added after one `nvgBeginPath()` share the same fill or stroke call.

## Custom paths

Use `nvgMoveTo()` to begin a contour and add segments:

```c
nvgBeginPath(vg);
nvgMoveTo(vg, 20.0f, 100.0f);
nvgBezierTo(vg, 60.0f, 20.0f, 140.0f, 180.0f, 180.0f, 100.0f);
nvgStrokeWidth(vg, 4.0f);
nvgStrokeColor(vg, nvgRGB(244, 63, 94));
nvgStroke(vg);
```

Angles passed to `nvgArc()` and transform rotation functions are radians. Use `nvgDegToRad()` when starting with degrees.

## Transform reusable geometry

Define a component in local coordinates and position it with saved state:

```c
nvgSave(vg);
nvgTranslate(vg, x, y);
nvgRotate(vg, nvgDegToRad(angleDegrees));

nvgBeginPath(vg);
nvgRect(vg, -40.0f, -16.0f, 80.0f, 32.0f);
nvgFillColor(vg, color);
nvgFill(vg);

nvgRestore(vg);
```

The transform active when segments are added becomes part of the path geometry.
