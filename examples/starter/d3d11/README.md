# NanoVG Direct3D 11 starter

This Windows starter contains the complete Win32 window, Direct3D 11 device,
swap-chain, resize, rendering, and presentation flow.

```sh
cmake -S . -B build
cmake --build build --config Release
```

Run `build/Release/nanovg_d3d11.exe`. Runtime fonts and images are copied from
`assets/` beside the executable.
